# 模型上下文協定（MCP）

Avro 可以連接遠端 MCP 伺服器，並把伺服器提供的工具交給支援工具呼叫的聊天模型。

## 新增伺服器

1. 開啟**設定 → MCP**。
2. 點選**新增 MCP 伺服器**。
3. 選擇 **Streamable HTTP** 或 **SSE**。
4. 輸入顯示名稱，以及以 http:// 或 https:// 開頭的伺服器 URL。
5. 只新增伺服器必要的自訂 HTTP 標頭，然後儲存。

Streamable HTTP 是目前的傳輸方式；SSE 用於相容舊版 MCP 伺服器。

自訂標頭值使用與 API 金鑰相同的機密設定儲存：通常由 Android Keystore AES-GCM 封裝，但舊值或加密失敗時可能為明文。其中可能包含授權權杖，請保護裝置與匯出檔案，且不要新增伺服器不需要的標頭。

## 連線與工具探索

已啟用的伺服器會在背景連線，狀態顯示為**閒置**、**連線中**、**已連線**或**連線錯誤**。可以在伺服器選單或編輯頁中選擇**重新連線**來重試探索。

連線成功後，Avro 會列出伺服器的工具。新探索的工具預設啟用；在伺服器編輯頁中可以逐項關閉。關閉整個伺服器會從後續模型請求中移除其全部工具，但不會刪除設定。

已啟用的 MCP 工具會進入 Avro 的標準工具呼叫流程。模型會看到工具名稱、說明和輸入結構，工具結果也會像其他工具呼叫一樣儲存在對話中。

## 編輯或刪除伺服器

點選伺服器可以編輯傳輸方式、名稱、URL、自訂標頭、連線狀態和已啟用工具。伺服器右側選單可用於重新連線或刪除。

刪除伺服器會移除其設定並停用對應工具，但不會刪除既有的對話歷史。

## 安全性

MCP 工具可能在外部系統產生副作用。請只連接可信任的伺服器、檢查工具清單，並授予盡可能小的憑證範圍。離開可信任的區域網路時，優先使用 HTTPS。

## 疑難排解

### 連線錯誤

- 確認 Android 裝置可以存取該 URL。
- 確認所選傳輸方式與伺服器相符。
- 檢查驗證標頭與伺服器記錄。
- 修改設定後使用**重新連線**。

### 沒有顯示工具

- 確認伺服器已啟用且狀態為**已連線**。
- 重新連線以重新整理工具探索。
- 開啟編輯頁，確認個別工具沒有被關閉。

### 模型沒有取得某個工具

目前模型與服務商必須支援工具呼叫，同時伺服器和該工具本身都必須處於啟用狀態。
