# 远程 Shell

打开**設定 → Shell 裝置**設定供代理工具使用的 Conch 或 SSH 裝置。

## Conch

設定伺服器 URL、可选 API Key 和命令确认策略。有 API Key 时，Avro 获取伺服器签名公钥，派生临时共享密钥，并发送经过认证的 AES-GCM 请求。空 Key 时應用程式层载荷是明文 JSON，机密性只依赖 HTTPS。

前台命令会建立持久任務并等待有限时间。等待超时不会杀死或重放命令，而是返回 `job_id`；之后可查询、等待、停止和确认刪除。Conch 还支援远程读取、写入、编辑、glob、grep 与图像查看。

## SSH 与确认

SSH 可設定主机、端口、使用者、认证和主机密钥验证/固定。直接 SSH 不受共享 HTTP 代理控制。命令可要求确认，或按伺服器设为始终允许；远程账户权限决定模型可执行的操作。
