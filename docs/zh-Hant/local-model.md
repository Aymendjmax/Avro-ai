# 本地模型

Avro 可匯入 GGUF 模型，通过 llama.cpp 在裝置端推理。

## 匯入与使用

打开**設定 → 提供商 → 本地**匯入 GGUF 檔案。Avro 会把模型复制到應用程式管理目录，并可在支援时关联多模态投影檔案。匯入的模型会自动启用，可从**設定 → 模型**或聊天模型选择器使用。

模型所需記憶體、上下文能力和速度取决于 GGUF 与裝置。大模型或大上下文可能很慢，或在記憶體不足时失败。

## 刪除

刪除已匯入模型会移除 Avro 管理的 GGUF 和关联投影檔案，不会刪除應用程式目录之外的无关源檔案。本地 llama.cpp 推理不依赖 Alpine 沙盒；后者是单独的 F-Droid 功能。
