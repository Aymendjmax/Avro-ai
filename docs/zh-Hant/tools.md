# 代理工具

Avro 可让模型在多轮生成中调用工具。

按設定、构建和提供商能力，可用工具包括：網路搜尋、图像生成、活跃/已儲存记忆、历史對話搜尋、MCP、任務与循环自动化、Conch/SSH 命令与持久任務、远程檔案操作、`view_image`，以及 F-Droid 构建中的 Alpine 沙盒。

## 权限与預設值

網路搜尋、活跃记忆、已儲存记忆、历史對話访问和全局 Shell 权限預設开启；Shell 仍需先設定裝置，并遵循该裝置的确认策略。自动化工具預設关闭。MCP 按伺服器与工具开关控制。

工具调用和结果会进入對話协议，并可能在后续轮次发送给模型。外部工具会收到执行所需參數，启用前应核对伺服器和权限。图像生成与嵌入使用各自所选提供商的凭据。
