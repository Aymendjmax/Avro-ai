# 生成參數

打开**設定 → 生成參數**設定預設请求參數；對話级覆盖可替换这些預設值。

## 常用參數

- 温度控制随机性。
- Top P 限制累计概率质量。
- Top K 在提供商支援时限制候选 Token。
- 最大输出 Token 限制回复长度。
- 频率惩罚和存在惩罚在支援时降低重复。

Avro 只会按所选提供商协议发送受支援的參數。

## 思考

可启用思考预算并选择 Token 预算，或选择模型支援的推理等级：**Minimal、Low、Medium、High、xHigh、Max**。不同提供商与模型的支援不一致。

## OpenAI 兼容服务层级

兼容端点可选 **Off、Auto、Default、Flex、Fast**。是否可用、延迟与计费由提供商决定。
