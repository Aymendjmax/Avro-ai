# 匯入与匯出

打开**設定 → 匯入与匯出**迁移或备份 Avro 数据。

## Avro 归档

`.avro` 是带版本的 ZIP 归档，当前格式版本为 4。按所选类别可包含：

- 對話、執行、消息、任務、循环及相关图数据；
- 附件、工具媒体和草稿媒体；
- 活跃记忆、已儲存记忆与技能（Skills）；
- 系统提示词；
- 應用程式設定和匯入的自定义字体；
- 仅在明确选择时包含的提供商 API Key 与其他机密。

!!! warning "保护包含机密的归档"
    机密在归档内部未加密。请像保护原始凭据一样儲存和传输该檔案。

原生匯入前，Avro 会加载预览并列出归档中的类别。對話、记忆、系统提示词、設定和 API Key 可分别选择**合并**、**替换**或**跳过**。如果当前應用程式不支援该归档版本，页面会显示错误并禁用匯入确认。

原生预览加载、匯入和匯出分别使用标为**加载中…**、**匯入中…**、**匯出中…**的不可取消圆形进度對話框。

## ChatGPT 与 Claude 匯入

可直接匯入 ChatGPT 和 Claude 匯出 ZIP。预览后可选择要匯入的對話。

- **合并**保留其他现有對話，并匯入选中的對話。
- **替换**刪除全部现有對話，只保留选中的匯入對話；开始前会再次显示破坏性确认。

这两类匯入使用不可取消的百分比线性进度對話框。Claude 的附件记录可能只有元数据而没有原檔案，取决于源匯出内容。

## 自动备份

WorkManager 可按所选目录、周期、类别和保留策略建立定期备份。Android 後台调度为尽力执行；电池策略和儲存访问可能影响实际时机。

详见[隐私与安全](privacy.md)。
