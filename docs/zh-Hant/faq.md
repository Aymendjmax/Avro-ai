# 常见问题

## Avro 是否经过自有伺服器转发聊天？

不会。對話儲存在本地，聊天请求由裝置直接发往你設定的提供商或端点。更新检查、主动提交评分或崩溃报告、網路搜尋、MCP、嵌入、图片服务和远程 Shell 等可选功能会访问各自的目标，详见[隐私与安全](privacy.md)。

## API 密钥儲存在哪里？

机密設定通常使用 Android Keystore 支援的 AES-256-GCM 封装；旧值可按明文读取，加密失败时会为避免丢失数据而回退为明文。备份中明确包含的机密也会在归档内部以未加密形式儲存。

## 支援哪些界面語言？

系统預設，以及英语、阿拉伯语、德语、西班牙语、法语、日语、韩语、巴西葡萄牙语、俄语、越南语、简体中文和繁体中文。没有维护翻譯时，网页手册会回退到英语。

## 为什么找不到模型？

打开**設定 → 模型**，同步提供商并启用模型；也可手动添加自定义模型。请确认提供商凭据和 Base URL 有效。

## Compact 会刪除历史消息吗？

不会。Compact 增加可见的摘要边界，原消息保留。它属于标准生成，期间发送的消息会排队；刪除胶囊会恢复前一个边界。详见[上下文](context.md)。

## Conch 是否始終端機到端加密？

只有設定 API Key 时才有應用程式层加密。空 Key 伺服器接收明文 JSON；若 URL 为 HTTPS，则只依赖 TLS。详见[Shell 設定](shell.md)。

## 如何备份？

使用**設定 → 匯入与匯出**。`.avro` 是 ZIP 归档，可选择类别并可选包含机密。详见[匯入与匯出](import-export.md)。
