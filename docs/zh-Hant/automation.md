# 自動化

Avro 提供持久化的**任務（Tasks）**和綁定到對話的**迴圈（Loops）**。自動化設定頁控制模型是否可以管理它們，以及 Android 的排程精確度。

## 任務

從應用程式導覽進入**任務**即可建立和管理排程提示詞。

每個任務包含：

- 名稱與提示詞；
- 可選的模型覆寫；
- 手動、單次、每日、每週、每月、每年或自訂五段式 cron 排程；
- 控制是否按排程執行的啟用開關。

使用**立即執行**可以不等待排程直接執行任務。每次執行都會產生帶狀態的歷史記錄和對應對話。關閉按排程執行後，任務仍可手動執行。

單次排程必須位於未來。過期日期會被拒絕，不會被靜默改到下一年。

## 對話迴圈

迴圈屬於某一個對話，會按設定的間隔繼續發起生成。每輪可以注入提示詞，並有最大輪數安全限制。一個對話同一時間最多只能有一個活動迴圈。

迴圈透過 Avro 的自動化工具啟動和停止，因此模型控制迴圈前必須啟用**存取任務與迴圈**。

## 存取任務與迴圈

此設定預設關閉。啟用後，模型可以使用工具：

- 建立、列出和刪除任務；
- 啟動或停止目前對話的迴圈。

工具執行時會再次檢查開關，因此關閉設定後，模型先前提出但尚未執行的自動化呼叫也不能再修改自動化狀態。

!!! warning
    僅在你希望模型修改持久化排程時啟用自動化存取。排程提示詞可能在背景呼叫模型服務商和已啟用工具。

## 排程精確度

Avro 預設使用較省電的非精確鬧鐘，因此 Android 可能延後執行。

啟用**精確執行**後，任務和迴圈會要求精確鬧鐘。在 Android 12 及以上版本中，系統可能開啟「鬧鐘和提醒」權限頁面。如果權限被拒絕或之後被撤銷，Avro 會關閉精確執行並安全回退到非精確排程。

精確鬧鐘可以改善時間準確性，但無法繞過 Android 的電池、背景、網路或廠商限制。

## 可靠性

任務和迴圈會重用標準對話生成流程；對話忙碌時不會建立第二套寫入流程。自動化執行期間會顯示常駐通知。如果目標對話正在生成，本次自動化會回傳忙碌結果，而不是建立競爭 Run。
