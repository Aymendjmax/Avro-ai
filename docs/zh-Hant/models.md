# 模型

打开**設定 → 模型**选择預設模型，并控制 Avro 可以使用哪些已設定模型。

## 預設模型

选择没有對話级模型覆盖时使用的全局預設模型。只有已启用模型会出现在此选择器和聊天模型选择器中。

## 自定义模型

当提供商发现介面未返回所需标识符时，可手动添加模型。每个条目儲存提供商、提供商原始模型 ID 和可选显示别名。编辑器会分别显示提供商与原始 ID；未儲存显式别名时，Avro 可以显示推断出的易读别名。

自定义模型按提供商分组。可用复选框启用或停用，也可打开条目编辑或刪除。

## 已获取模型

**从所有提供商同步**会从已設定提供商获取模型目录。未設定的提供商会跳过，同步能力取决于提供商。

进入页面时，仅当当前提供商設定指纹与上次完整同步尝试的指纹不同，Avro 才自动同步。一次非取消的完成尝试会儲存啟動时捕获的指纹，即使部分提供商失败；取消不会儲存。无需更改提供商設定，也可点击同步行手动重试。

同步期间，该行会以 250 ms Crossfade 切换为**正在同步...**和 24 dp 圆形进度指示器。开始时不显示 Snackbar，完成后才报告结果。

已获取模型按提供商分组，可按提供商、原始模型 ID、已儲存别名或推断别名搜尋。列表会把易读名称与提供商/API 标识分开显示。用复选框控制模型是否可用，并通过别名操作修改显示名称。

停用任意模型会将其从选择列表移除。刪除手动添加的模型只会移除该本地設定条目；这两种操作都不会刪除远程提供商数据。匯入的聊天 GGUF 檔案在[提供商](provider.md)的本地提供商下管理。

## 模型名称中的 Provider

重命名對話框和自定义模型编辑器的别名输入框下方都有**显示 Provider 名称**开关。开启时，完整模型名称显示为 `模型名称 (Provider)`；关闭时只显示模型名称。修改或清空别名不会改变开关。設定中按提供商分组的列表仍单独展示提供商訊息。

点击 **Save（儲存）**才会一起儲存别名和开关；取消、返回或点击對話框外部都不会儲存。新模型預設显示 Provider。升级后，Avro 只会初始化一次开关，以保持已有模型此前的显示效果。此設定包含在設定备份中。

详见[提供商](provider.md)和[生成](generation.md)。
