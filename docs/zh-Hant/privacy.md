# 隱私與安全

Avro 是 BYOK 用戶端，不營運聊天補全中繼服務：請求從裝置直接送往你設定的服務商、模型伺服器或工具端點。

## 裝置上的資料

對話、訊息樹、工作、循環、記憶、提示詞、附件和工具媒體保存在應用程式管理的資料庫/檔案中。一般設定使用 Android 偏好。機密通常使用 Android Keystore 支援的 AES-256-GCM 封裝；舊明文仍可讀取，加密失敗時會為避免遺失資料而回退為明文。

## 資料何時離開裝置

只有使用相應功能時才產生流量：模型與嵌入請求送往所選服務商；網路搜尋送往所選搜尋服務；MCP、Conch 與 SSH 操作送往已設定端點；應用程式啟動時最多每天一次取得更新中繼資料。可選評分表單只會提交你填寫的評分、姓名、電子郵件和留言。崩潰後只在本機保存一份待處理報告；下次啟動時由你明確選擇是否傳送堆疊、應用程式/Android 版本、裝置廠商/型號、時間戳和有界診斷事件。報告不會自動上傳，也不含對話文字、憑證或裝置識別碼。

`.avro` 是 ZIP 封存檔；若明確包含機密，這些值在封存檔內未加密。網路 Proxy 只涵蓋共用 HTTP 用戶端流量。Conch 的應用層加密需要 API 金鑰；空金鑰依賴 HTTPS 保護傳輸。
