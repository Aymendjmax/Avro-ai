# 工作模式與自主代理環境 (Work Mode)

Avro 提供兩種運作模式：**提問模式 (Ask Mode)**（輕量對話與諮詢）與 **工作模式 (Work Mode)**（具備本機終端、沙盒執行與檔案產出交付的自主 Linux 代理）。

---

## 1. 運作模式對比

| 功能特性 | 提問模式 (Ask Mode - 預設) | 工作模式 (Work Mode) |
| :--- | :--- | :--- |
| **核心定位** | 快速對話答疑、搜尋與知識檢索 | 自主程式碼執行、系統構建與複雜任務完成 |
| **Shell 與命令工具** | 嚴格隔離禁用，防止非預期操作並節省 Token | 完整啟用 (`execute_shell_command` 與檔案工具) |
| **PRoot Linux 沙盒** | 休眠狀態 | 啟用裝置端獨立的 Alpine Linux 3.21 環境 |
| **成果交付 (`present_files`)** | 不啟用 | 自動將產出檔案作為互動式卡片交付 |
| **圖片本機檢查 (`view_image`)** | 禁用 | 支援直接檢查工作區內的圖片檔案 |
| **模式升級管道** | 模型可呼叫 `request_work` 彈卡請求權限 | 已在工作模式中 |

---

## 2. 模式切換

您可以在任何時候切換 **Ask** 與 **Work** 模式：
- **附加面板 (`+`)**：在輸入框左側點擊 `+`，直接在底部選單中切換 Ask / Work。
- **輸入列工作指示膠囊**：進入工作模式後，模型選擇器旁會出現明顯的 `Work` 膠囊，點擊可直接打開工作模式設定。
- **互動式 `request_work` 申請卡**：如果在提問模式下，AI 偵測到您的任務需要操作檔案系統或執行程式碼，它會自動呼叫 `request_work` 觸發確認卡，由您一鍵批准升級。

---

## 3. 裝置端 Linux 沙盒與 FileStore

工作模式執行於裝置上的 **Alpine Linux 3.21 PRoot** 容器，無需 Root 權限，本機完全離線可用。

### 持久化目錄結構 (`/home/`)
- `/home/uploads/<chatId>/`：當前對話上傳的附件檔案。
- `/home/outputs/<chatId>/`：AI 生成的交付檔案、圖表、腳本與匯出結果。
- `/home/projects/`：持久化跨對話專案與 Git 倉庫。
- `/home/notes/`：筆記空間與任務索引。

---

## 4. 成果物卡片與即時預覽 (`present_files`)

智能體完成程式碼、Markdown、HTML 或資料檔案後，會透過 `present_files` 交付。

### 交付物卡片特色：
- **直覺卡片**：顯示檔名、格式徽章、格式化大小、路徑及分享按鈕。
- **全螢幕預覽面板**：點擊卡片即打開全螢幕檢視器：
  - **程式碼高亮**：對各類程式語言進行語法高亮顯示。
  - **Markdown 渲染**：排版展示標題、表格與列表。
  - **HTML 即時網頁預覽**：針對 HTML 交付物，提供「原始碼 / 即時預覽」一鍵切換。
  - **操作選單**：右上角選單支援一鍵下載至 `Downloads/Avro`、複製內容、系統分享以及列印/儲存為 PDF。

---

## 5. 本機圖片感知 (`view_image`)

在工作模式下，模型可直接檢視沙盒中的圖片：
- **多模態視覺模型**：圖片高畫質壓縮並直接作為上下文傳入。
- **純文字模型**：自動呼叫本機圖片解析器並根據預設提示詞生成描述。

---

## 6. MCP 與 Shell 檔案橋樑 (`file:<path>`)

- 輸入框支援 `@server` 喚起特定 MCP 工具。
- MCP 工具與 Shell 共享 `file:<path>` 協定，直接讀取或輸出沙盒路徑檔案。

---

## 7. 工作模式設定與儲存管理

進入 **設定 → 工作模式** 可進行：
- **新對話預設模式**：設定預設以 Ask 還是 Work 模式啟動新對話。
- **`request_work` 權限開關**：控制模型是否可以主動申請切換到工作模式。
- **沙盒運作狀態**：檢視 PRoot 狀態與環境重設。
- **儲存佔用統計與清理**：檢視 uploads、outputs、projects 佔用空間，並提供安全清理選項。
