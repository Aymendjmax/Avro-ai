# Alpine 沙盒

集成的 PRoot Alpine Linux 为代理程式碼执行提供隔离的使用者态命令环境。

## 可用性

沙盒仅在 F-Droid 构建中提供。Google Play 构建使用不可用实现，不提供等价执行能力。

## 管理

在**設定 → 沙盒**中可启用功能、安装或升级 RootFS、查看軟體包、浏览檔案以及重置环境。共享儲存挂载可让沙盒访问选定 Android 檔案；只授予必要范围，因为沙盒命令可以修改已挂载内容。

## 安全边界

PRoot 是进程/檔案系统隔离，不是硬件虚拟机，也不会获得 Android Root。命令仍可使用應用程式已经获得的权限。VPN、私有 DNS、门户網路或 Android 後台策略可能影响下载与联网。
