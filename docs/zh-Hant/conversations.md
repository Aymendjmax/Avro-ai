# 對話

Avro 将對話儲存为消息树。编辑历史消息或重新生成回复会建立新分支，不会刪除其他分支。

## 建立与导航

通过對話抽屉新建、重命名、搜尋、置顶、归档或刪除對話。聊天中的分支控件用于切换同一父节点下的备选回复。

## 发送与生成

底栏用于选择模型并显示估算的上下文占用。普通生成（包括 Compact）共享同一发送状态：没有草稿或附件时按钮显示为**停止**；有待发送内容时仍显示**发送**并进入队列，当前生成结束后自动发送。

长對話的预算和 Compact 行为在**設定 → 上下文**中設定。详见[上下文](context.md)。

## 标题、提示词与附件

對話标题可由[标题生成](title-generation.md)自动生成；對話可继承預設[系统提示词](system-prompts.md)或选择其他提示词。编辑器支援图片、视频、PDF 和檔案，实际处理方式取决于模型与相关設定。
