# 对话搜索

打开**设置 → 对话搜索**配置对历史对话的关键词与语义访问。

## 访问

**访问历史对话**默认开启。关闭后，模型的对话搜索工具不会检索旧对话。活跃记忆和已保存记忆有独立权限。

## 缓存

**自动缓存新消息**默认开启。存在活动嵌入模型时，Avro 会为新持久化的可搜索消息建立索引。切换活动嵌入模型时，如自动缓存仍开启，还会补齐该模型缺失的消息嵌入。

关闭自动缓存后，新消息会保持未缓存，直至手动开始缓存。此时才显示**显示未缓存通知**，用于控制可提供**立即缓存**操作的提醒。

## 搜索方式

以下两条路径可分别选择**关键词**或**语义（RAG）**：

- **模型搜索方式**：模型通过工具调用搜索历史对话时使用；
- **手动搜索方式**：对话抽屉搜索栏使用。

至少配置一个嵌入模型后才能选择语义搜索；关键词搜索不依赖嵌入缓存。

## 嵌入模型

可添加远程嵌入端点，或导入本地 GGUF 嵌入模型。同一时间只有一个活动模型。每行会显示本地/远程类型，以及该模型已缓存的可搜索消息数量。

使用**缓存**补齐缺失的嵌入。当前消息全部缓存后，操作会变为**重新缓存**，重建前需要确认。启用自动缓存时，切换活动模型也会补齐其缺失条目。

远程嵌入模型会收到需要生成嵌入的文本；索引和缓存状态保存在本地。

## 高级检索

可配置：

- 4–32 个对话步骤的上下文范围；
- 5–30 条返回结果；
- 0–1 的相似度阈值，默认 0.5。

详见[嵌入 / RAG](embedding.md)、[记忆与缓存](memory.md)和[隐私与安全](privacy.md)。
