# 代理工具

Avro 可让模型在多轮生成中调用工具。

按设置、构建和提供商能力，可用工具包括：网络搜索、图像生成、活跃/已保存记忆、历史对话搜索、MCP、任务与循环自动化、Conch/SSH 命令与持久任务、远程文件操作、`view_image`，以及 F-Droid 构建中的 Alpine 沙盒。

## 权限与默认值

网络搜索、活跃记忆、已保存记忆、历史对话访问和全局 Shell 权限默认开启；Shell 仍需先配置设备，并遵循该设备的确认策略。自动化工具默认关闭。MCP 按服务器与工具开关控制。

工具调用和结果会进入对话协议，并可能在后续轮次发送给模型。外部工具会收到执行所需参数，启用前应核对服务器和权限。图像生成与嵌入使用各自所选提供商的凭据。
