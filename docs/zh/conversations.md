# 对话

Avro 将对话保存为消息树。编辑历史消息或重新生成回复会创建新分支，不会删除其他分支。

## 创建与导航

通过对话抽屉新建、重命名、搜索、置顶、归档或删除对话。聊天中的分支控件用于切换同一父节点下的备选回复。

## 发送与生成

底栏用于选择模型并显示估算的上下文占用。普通生成（包括 Compact）共享同一发送状态：没有草稿或附件时按钮显示为**停止**；有待发送内容时仍显示**发送**并进入队列，当前生成结束后自动发送。

长对话的预算和 Compact 行为在**设置 → 上下文**中配置。详见[上下文](context.md)。

## 标题、提示词与附件

对话标题可由[标题生成](title-generation.md)自动生成；对话可继承默认[系统提示词](system-prompts.md)或选择其他提示词。编辑器支持图片、视频、PDF 和文件，实际处理方式取决于模型与相关设置。
