# 导入与导出

打开**设置 → 导入与导出**迁移或备份 Avro 数据。

## Avro 归档

`.avro` 是带版本的 ZIP 归档，当前格式版本为 4。按所选类别可包含：

- 对话、运行、消息、任务、循环及相关图数据；
- 附件、工具媒体和草稿媒体；
- 活跃记忆、已保存记忆与技能（Skills）；
- 系统提示词；
- 应用设置和导入的自定义字体；
- 仅在明确选择时包含的提供商 API Key 与其他机密。

!!! warning "保护包含机密的归档"
    机密在归档内部未加密。请像保护原始凭据一样存储和传输该文件。

原生导入前，Avro 会加载预览并列出归档中的类别。对话、记忆、系统提示词、设置和 API Key 可分别选择**合并**、**替换**或**跳过**。如果当前应用不支持该归档版本，页面会显示错误并禁用导入确认。

原生预览加载、导入和导出分别使用标为**加载中…**、**导入中…**、**导出中…**的不可取消圆形进度对话框。

## ChatGPT 与 Claude 导入

可直接导入 ChatGPT 和 Claude 导出 ZIP。预览后可选择要导入的对话。

- **合并**保留其他现有对话，并导入选中的对话。
- **替换**删除全部现有对话，只保留选中的导入对话；开始前会再次显示破坏性确认。

这两类导入使用不可取消的百分比线性进度对话框。Claude 的附件记录可能只有元数据而没有原文件，取决于源导出内容。

## 自动备份

WorkManager 可按所选目录、周期、类别和保留策略创建定期备份。Android 后台调度为尽力执行；电池策略和存储访问可能影响实际时机。

详见[隐私与安全](privacy.md)。
