# 工作模式与自主智能体环境 (Work Mode)

Avro 提供两种运行模式：**提问模式 (Ask Mode)**（轻量对话与咨询）与 **工作模式 (Work Mode)**（具备本地终端、沙盒执行与文件产出交付的自主 Linux 智能体）。

---

## 1. 运行模式对比

| 功能特性 | 提问模式 (Ask Mode - 默认) | 工作模式 (Work Mode) |
| :--- | :--- | :--- |
| **核心定位** | 快速对话答疑、搜索与知识检索 | 自主代码执行、系统构建与复杂任务完成 |
| **Shell 与命令工具** | 严格隔离禁用，防止非预期操作并节省 Token | 完整启用 (`execute_shell_command` 与文件工具) |
| **PRoot Linux 沙盒** | 休眠状态 | 激活设备端独立的 Alpine Linux 3.21 环境 |
| **成果交付 (`present_files`)** | 不启用 | 自动将产出文件作为交互式卡片交付 |
| **图像本地检查 (`view_image`)** | 禁用 | 支持直接检查工作区内的图片文件 |
| **模式升级通道** | 模型可调用 `request_work` 弹卡请求权限 | 已在工作模式中 |

---

## 2. 模式切换

您可以在任何时候切换 **Ask** 与 **Work** 模式：
- **附加面板 (`+`)**：在输入框左侧点击 `+`，直接在底部菜单中切换 Ask / Work。
- **输入栏工作指示胶囊**：进入工作模式后，模型选择器旁会出现明显的 `Work` 胶囊，点击可直接打开工作模式设置。
- **交互式 `request_work` 申请卡**：如果在提问模式下，AI 检测到您的任务需要操作文件系统或运行代码，它会自动调用 `request_work` 触发确认卡，由您一键批准升级。

---

## 3. 设备端 Linux 沙盒与 FileStore

工作模式运行于设备上的 **Alpine Linux 3.21 PRoot** 容器，无需 Root 权限，本地完全离线可用。

### 持久化目录结构 (`/home/`)
- `/home/uploads/<chatId>/`：当前会话上传的附件文件。
- `/home/outputs/<chatId>/`：AI 生成的交付文件、图表、脚本与导出结果。
- `/home/projects/`：持久化跨会话代码项目与 Git 仓库。
- `/home/notes/`：笔记空间与任务索引。

---

## 4. 成果物卡片与即时预览 (`present_files`)

智能体完成代码、Markdown、HTML 或数据文件后，会通过 `present_files` 交付。

### 交付物卡片特色：
- **直观卡片**：显示文件名、格式徽标、格式化大小、路径及分享按钮。
- **全屏预览面板**：点击卡片即打开全屏查看器：
  - **代码高亮**：对各类编程语言进行语法高亮显示。
  - **Markdown 渲染**：排版展示标题、表格与列表。
  - **HTML 实时网页预览**：针对 HTML 交付物，提供“源码 / 实时预览”一键切换。
  - **操作菜单**：右上角菜单支持一键下载至 `Downloads/Avro`、复制内容、系统分享以及打印/保存为 PDF。

---

## 5. 本地图像感知 (`view_image`)

在工作模式下，模型可直接查看沙盒中的图片：
- **多模态视觉模型**：图像高质量压缩并直接作为上下文传入。
- **纯文本模型**：自动调用本地图像解析器并根据预设提示词生成描述。

---

## 6. MCP 与 Shell 文件桥梁 (`file:<path>`)

- 输入框支持 `@server` 唤起特定 MCP 工具。
- MCP 工具与 Shell 共享 `file:<path>` 协议，直接读取或输出沙盒路径文件。

---

## 7. 工作模式设置与存储管理

进入 **设置 → 工作模式** 可进行：
- **新会话默认模式**：设定默认以 Ask 还是 Work 模式启动新对话。
- **`request_work` 权限开关**：控制模型是否可以主动申请切换到工作模式。
- **沙盒运行状态**：查看 PRoot 状态与环境重置。
- **存储占用统计与清理**：查看 uploads、outputs、projects 占用空间，并提供安全清理选项。
