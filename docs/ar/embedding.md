# التضمين الشعاعي والـ RAG

تقوم نماذج التضمين الشعاعي (Embedding Models) بتحويل نصوص المحادثات إلى متجهات رقمية تُستخدم في البحث الدلالي الذكي داخل المحادثات. يمكن تهيئتها عبر **الإعدادات ← البحث في المحادثات**.

## المزودون والخيارات المسبقة
تشمل النماذج المدعومة حالياً:
- **OpenAI**: `text-embedding-3-small` و `text-embedding-3-large` و `text-embedding-ada-002`
- **Mistral**: `mistral-embed`
- **Voyage AI**: `voyage-3-large` و `voyage-3-lite` و `voyage-code-3`
- **SiliconFlow**: `BAAI/bge-m3` و `BAAI/bge-large-en-v1.5`
- **OpenRouter**: مسارات نماذج التضمين المتوافقة مع OpenAI
- **Ollama أو النماذج المحلية**: نماذج GGUF مدمجة على جهازك بالكامل، أو عبر نقاط نهاية مخصصة (Custom Endpoints).

تستخدم نماذج التضمين البعيدة بيانات الاعتماد ورابط الـ API الخاص بالمزود المختار، وبالتالي فإن النص المراد تضمينه يغادر جهازك إلى ذلك المزود. أما نماذج التضمين المحلية فتعمل محلياً بنسبة 100% على هاتفك.

## معايير الـ RAG (الاسترجاع المعزز بالتوليد)
- **نطاق السياق (Context range)**: من 4 إلى 32 خطوة محادثة (بزيادات قدرها 4 خطوات).
- **عدد النتائج (Result count)**: من 5 إلى 30 نتيجة (بزيادات قدرها 5).
- **عتبة التشابه (Similarity threshold)**: من 0 إلى 1 (القيمة الافتراضية هي 0.5).

تغيير نموذج التضمين قد يتطلب إعادة تضمين المحتوى المفهرس سابقاً قبل اكتمال دقة نتائج البحث. راجع [البحث في المحادثات](search.md) و [الخصوصية وأمان البيانات](privacy.md).
