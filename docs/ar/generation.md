# التحكم في التوليد

يوفر Avro إعدادات دقيقة للتحكم في كيفية استجابة النماذج.

## معلمات التوليد

- **Temperature**: ضبط الإبداع أو الدقة الحسابية.
- **Top-P و Top-K**: التحكم في فضاء احتمالات الكلمات المنتقاة.
- **Thinking Budget**: دعم نماذج التفكير والاستدلال المتقدم (Reasoning Models) وتحديد ميزانية التفكير بشكل منفصل.
