# الخصوصية وأمان البيانات (Privacy & Security)

يعتمد تطبيق Avro على مبدأ **الخصوصية أولاً والتخزين المحلي الصارم**.

## التخزين المحلي وأمان البيانات
- يتم تخزين جميع المحادثات، والرسائل، والمهام المجدولة، والذكريات، وقواعد البيانات محلياً على هاتفك فقط باستخدام قاعدة بيانات SQLite Room المشفرة التابعة للتطبيق.
- لا توجد أي خوادم وسيطة خاصة بنا تسجل محادثاتك أو تستقبل بياناتك.
- يتم تخزين مفاتيح الـ API وترويسات الاعتماد الحساسة في مساحة تخزين محمية بنظام تشفير قوي يعتمد على غلاف **Android Keystore AES-256-GCM**.

## الاتصالات الخارجية والشبكة
- عندما ترسل رسالة في المحادثة، يتصل هاتفك مباشرة بنقطة النهاية (Endpoint) الخاصة بالمزود الذي قمت بتهيئته (مثل OpenAI أو Anthropic أو Google أو مزودك المخصص).
- عند تفعيل البحث في الويب، تُرسل كلمات البحث مباشرة لمحرك البحث المختار (مثل DuckDuckGo، أو Brave، أو Tavily).
- عند الاتصال بخوادم MCP أو أوامر Conch/SSH البعيدة، تنتقل البيانات مباشرة بين هاتفك وتلك الخوادم عبر البروتوكولات المشفرة.

## التقارير والتقييمات
- في حال إرسال تقييم أو ملاحظة أو تقرير عطل عبر شاشات الإعدادات، يتم إرسال المعلومات الاختيارية التي يوافق عليها المستخدم فقط لتحسين تجربة التطبيق وتطوير الميزات.
- يمكنك مراجعة الكود البرمجي المصدري للتطبيق بالكامل على مستودع GitHub للتأكد من نزاهة التطبيق وشفافيته التامة.
