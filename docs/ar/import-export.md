# الاستيراد والتصدير

بياناتك ملكك بالكامل ويمكنك نقلها في أي وقت.

## التنسيقات المدعومة

- **حزم Avro (.avro / .agora)**: تصدير كامل وشامل للمحادثات، الإعدادات، والذاكرة.
- **استيراد من منصات أخرى**: استيراد سجلات المحادثات من ChatGPT و Claude بصيغة JSON.
- **النسخ الاحتياطي التلقائي**: جدولة نسخ احتياطي دوري في مساحة التخزين المحلية.
