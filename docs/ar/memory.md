# الذاكرة والتخزين المؤقت (Memory & Cache)

يوفر Avro مصدرين للذاكرة يمكن للنماذج الوصول إليهما:
- **الذاكرة النشطة (Active memory)**: معلومات موجزة ومهمة تكون متاحة تلقائياً عبر جميع المحادثات وتُحقن في تعليمة النظام.
- **الذكريات المحفوظة (Saved memories)**: ملفات وسجلات ذاكرة دائمة يمكن للأدوات قراءتها والبحث فيها وتحديثها تدريجياً.

الوصول إلى الذاكرة النشطة والذكريات المحفوظة مفعل افتراضياً ويمكن التحكم في كل منهما بشكل مستقل. أما الوصول إلى سجل المحادثات السابقة فيتم ضبطه عبر **الإعدادات ← البحث في المحادثات** وليس من هذه الصفحة.

تُحفظ بيانات الذاكرة محلياً في جهازك حتى تقوم بحذفها بنفسك. عندما يستخدم نموذج أو أداة مفعلة الذاكرة، قد يتم إرسال المحتوى المعني إلى مزود الخدمة لتلك المحادثة. مسح التخزين المؤقت (Cache) يختلف عن حذف الذاكرة الدائمة؛ راجع نصوص التأكيد بعناية قبل اتخاذ أي إجراء. راجع [البحث في المحادثات](search.md)، و [بيئة الأدوات](tools.md)، و [الخصوصية وأمان البيانات](privacy.md).
