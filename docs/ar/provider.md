# مزودو الذكاء الاصطناعي (AI Providers)

افتح **الإعدادات ← مزودو الخدمة** لإدارة بيانات الاعتماد، والروابط الأساسية، والبروتوكولات الخاصة بكل مزود ذكاء اصطناعي.

## المزودون المدمجون
يوفر Avro إعدادات مسبقة ومجهزة لأشهر المزودين، بما في ذلك:
- **OpenAI** (مع دعم كامل لـ ChatGPT, GPT-4o, o1, o3-mini وغيرها).
- **Anthropic** (نماذج Claude 3.5 Sonnet, Claude 3 Opus, Claude 3.5 Haiku مع ميزة Prompt Caching الموفرة للتكلفة).
- **Google Gemini** (Gemini 2.0 Flash, Gemini 1.5 Pro مع دعم النوافذ السياقية الضخمة).
- **Groq** (سرعات استجابة فائقة لمعالجة النماذج المفتوحة).
- **Mistral AI**, **DeepSeek**, **Perplexity**, **OpenRouter**, **Together AI**, **SiliconFlow**, **Ollama** وغيرها.

## المزودون المخصصون (Custom Providers)
يمكنك إضافة أي عدد من المزودين المخصصين الذين يتوافقون مع بروتوكولات:
- **OpenAI-compatible**: يغطي معظم الخوادم البديلة، وموزعي الـ API، ومشاريع vLLM، و LocalAI، وغيرها.
- **Anthropic-compatible**: للخوادم والوسطاء الذين يعملون بنفس بروتوكول أنثروبيك.
- **Responses API**: يدعم التبديل من Chat Completions إلى نقطة النهاية `/responses` الجديدة لدى المزودين الداعمين.

## مفاتيح الـ API المتعددة (Multiple API Keys)
يمكن لكل مزود تخزين مفاتيح API متعددة بأسماء مخصصة (مثلاً: مفتاح العمل، المفتاح الشخصي). يتيح لك زر الاختيار تفعيل أحد المفاتيح ليصبح هو النشط فوراً دون الحاجة لإعادة كتابة المفاتيح القديمة.

## كاش أنثروبيك (Anthropic Prompt Cache)
لمزود Anthropic والمزودين المتوافقين معه، يتوفر خيار متقدم لـ **التخزين المؤقت للتعليمات (Cache)**:
- مفعل افتراضياً لتوفير ما يصل إلى 90% من تكلفة التوكنز في المحادثات الطويلة.
- يتيح لك تحديد مدة الاحتفاظ بالكاش: **5 دقائق (5m)** أو **ساعة واحدة (1h)**.
- يمكن إيقافه في حال كان الخادم الوسيط يقوم بإدارة التخزين المؤقت من تلقاء نفسه.

## المزود المحلي (Local Provider)
مخصص لإدارة نماذج GGUF المحلية التي تعمل بالكامل على معالج هاتفك دون الحاجة لشبكة الإنترنت. راجع [النماذج المحلية](local-model.md) و [إدارة النماذج](models.md).
