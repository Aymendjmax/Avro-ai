# البروكسي والشبكة (Network Proxy)

افتح **الإعدادات ← بروكسي الشبكة** لتوجيه حركة مرور عميل HTTP المشترك الخاص بتطبيق Avro عبر خادم وكيل (Proxy).

## النطاق والشمول
يمكن أن يؤثر البروكسي على: طلبات مزودي الذكاء الاصطناعي، ومزامنة كتالوج النماذج، والبحث في الويب، واتصالات MCP عبر بروتوكول HTTP، وفحص التحديثات، وتقارير الأعطال أو التقييمات عند استخدام عميل HTTP المشترك.

لا يقوم البروكسي بتمرير الآتي تلقائياً:
- اتصالات SSH المباشرة.
- استدلال النماذج المحلية بنظام llama.cpp على الجهاز.
- العمليات وحركة مرور الشبكة داخل بيئة ساندبوكس Alpine Linux المعزولة.

قد يظل الخادم الوجهة قادراً على رؤية البيانات الوصفية للاتصال، ويمكن لمشغل البروكسي مراقبة حركة المرور وفق مستوى التشفير المستخدم لنقل البيانات.

## المصادقة وقواعد الاستثناء
قم بتهيئة نوع البروكسي (HTTP / SOCKS5)، وعنوان المضيف (Host)، والمنفذ (Port)، واسم المستخدم وكلمة المرور إن وجدت، وقواعد الاستثناء (Bypass Rules) التي تقبلها الواجهة. اختبر المسار دائماً قبل الاعتماد عليه في المهام الحساسة. يتم تضمين كلمة مرور البروكسي في ملف تصدير Avro فقط إذا تم اختيار فئة الأسرار والمفاتيح صراحة. راجع [الخصوصية وأمان البيانات](privacy.md).
