# البحث في الويب (Web Search)

افتح **الإعدادات ← البحث في الويب** لاختيار محرك البحث المفضل وعدد النتائج المسترجعة.

## المحركات المدعومة
يدعم Avro مجموعة من أقوى محركات البحث:
- **DuckDuckGo**: الخيار الافتراضي؛ مجاني ويعمل مباشرة دون الحاجة لأي مفتاح API.
- **Brave Search**: يتطلب مفتاح API من Brave.
- **Tavily AI**: محرك بحث مخصص لوكلاء الذكاء الاصطناعي مع نتائج مفلترة وموجزة.
- **Serper**: محرك متوافق مع نتائج Google Search عبر API.
- **Kagi**: محرك بحث سريع وخالٍ من الإعلانات يتطلب مفتاح اشتراك Kagi.
- **SearXNG**: محرك بحث مفتوح المصدر ومستقل يتطلب إدخال رابط نسختك الخاصة (Instance URL).

البحث في الويب مفعل افتراضياً. وعدد النتائج الافتراضي هو 5 نتائج، ويمكن ضبطه بحرية بين 1 إلى 10 نتائج.

## مسار البيانات والخصوصية
تُرسل استعلامات البحث مباشرة من جهازك إلى محرك البحث المختار. تُحفظ المقتطفات والروابط المرجعية ضمن بيانات أدوات المحادثة وتُرسل إلى نموذج الدردشة ليقوم بصياغة إجابة محدثة وموثقة بالمصادر الحية. تخضع سياسات المحركات وتوفرها لجهات خارجية مستقلة عن تطبيق Avro. راجع [بيئة الأدوات](tools.md) و [الخصوصية وأمان البيانات](privacy.md).
