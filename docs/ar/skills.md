# مهارات الوكلاء (Agent Skills)

المهارات (Skills) هي ملفات تعليمات وإرشادات برمجية بصيغة Markdown قابلة لإعادة الاستخدام ومخزنة محلياً في جهازك داخل تطبيق Avro.

## آلية العمل والصلاحيات
عند تفعيل **السماح بالوصول إلى المهارات (Allow skill access)**:
- تقوم كل عملية توليد جديدة بتجميد كتالوج موجز يحتوي فقط على أسماء ملفات المهارات وشروحاتها الموجزة.
- يستطيع النموذج حينها استخدام أدوات المهارات لسرد الملفات، أو قراءتها، أو إنشائها، أو تعديلها، أو حذفها.
- لا يتم حشو نصوص المهارات الكاملة داخل كل طلب تلقائياً لتجنب إهدار التوكنز؛ بل يقرأ النموذج محتوى المهارة المعنية عند الحاجة إليها فقط.

لا يحتوي Avro على زر تفعيل لمهارة واحدة مفردة؛ إذ يؤثر تعديل أي مهارة على عمليات التوليد المستقبلية، بينما تحتفظ المحادثة الجارية بكتالوجها وسياساتها المجمدة مسبقاً.

تُدرج المهارات تلقائياً ضمن النسخ الاحتياطي الأصلي `.avro` والأتمتة الدورية. ويمكن عند الاستيراد دمجها أو استبدال قاعدة بيانات المهارات المحلية بحسب الوضع المختار.
