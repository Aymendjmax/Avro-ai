# الاتصال الطرفي البعيد (Remote Shell)

افتح **الإعدادات ← أجهزة الشل (Shell Devices)** لتهيئة خوادم Conch أو أجهزة SSH التي يمكن لأدوات الوكلاء الذاتية الاتصال بها وتنفيذ الأوامر عليها.

## خوادم Conch
قم بتهيئة رابط خادم Conch، ومفتاح الـ API الاختياري، وسياسة تأكيد الأوامر:
- مع وجود مفتاح API، يجلب Avro المفتاح العام الموقع للخادم، ويشتق مفتاحاً مشتركاً مؤقتاً، ويرسل طلبات مصادقة مشفرة بنظام AES-GCM فائق الأمان.
- إذا كان حقل المفتاح فارغاً، تكون حمولة التطبيق عبارة عن JSON عادي وتعتمد سرية النقل حصراً على حماية شهادة HTTPS.
- تُنشأ الأوامر الأمامية كمهام خادم دائمة (Durable Jobs) وينتظرها التطبيق لفترة محددة. إذا انتهت مهلة الانتظار، لا يتم إنهاء الأمر قسراً أو إعادة تشغيله؛ بل يرجع Avro معرّف المهمة `job_id` الذي يمكن فحصه، ومتابعته، وإيقافه، وتأكيده لاحقاً.
- تدعم أدوات Conch أيضاً القراءة، والكتابة، والتعديل، والبحث في الملفات (Glob/Grep)، واستعراض الصور عن بعد.

## خوادم SSH المباشرة
قم بتهيئة عنوان المضيف (Host)، والمنفذ (Port)، والمستخدم، وطريقة المصادقة، والتحقق من بصمة مفتاح المضيف وتثبيتها (Pinning). اتصال SSH المباشر منفصل تماماً عن بروكسي HTTP المشترك الخاص بـ Avro.

## سياسة التأكيد والحذر
يمكن ضبط الأوامر لتتطلب موافقتك اليدوية في كل مرة، أو السماح بها دائماً لكل خادم مهيأ على حدة. تعامل مع كلا النوعين من الخوادم كقدرات عالية الحساسية؛ إذ تحدد صلاحيات الحساب البعيد ما يمكن للنموذج الوصول إليه أو تغييره في خوادمك. راجع [بيئة الأدوات](tools.md)، و [البروكسي والشبكة](proxy.md)، و [الخصوصية وأمان البيانات](privacy.md).
