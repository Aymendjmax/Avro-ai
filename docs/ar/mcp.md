# بروتوكول سياق النماذج (MCP - Model Context Protocol)

يتيح Avro الاتصال بخوادم بروتوكول MCP الخارجية لتمكين نماذج الذكاء الاصطناعي من استدعاء أدواتها واستخدام قدراتها المتنوعة.

## إضافة خادم MCP جديد
1. افتح **الإعدادات ← خوادم MCP**.
2. اضغط على **إضافة خادم MCP (Add MCP Server)**.
3. اختر نوع بروتوكول النقل: **Streamable HTTP** (الحديث الموصى به) أو **SSE** (للخوادم الأقدم).
4. اكتب اسماً مخصصاً للخادم، ورابط الـ URL (يبدأ بـ http:// أو https://).
5. أضف ترويسات HTTP المخصصة المطلوبة للمصادقة فقط، ثم احفظ.

يتم تخزين ترويسات HTTP المخصصة بنفس الطريقة المشفرة الآمنة المتبعة لمفاتيح الـ API: عبر غلاف مشفر بنظام AES-GCM مدعوم بمخزن مفاتيح الأندرويد (Android Keystore). ونظراً لأنها قد تحتوي على رموز توكنز تفويض حساسة، احرص على حماية جهازك وملفات النسخ الاحتياطي ولا تضف ترويسات لا يطلبها الخادم.

## الاتصال واكتشاف الأدوات تلقائياً
يتصل الخادم المفعل تلقائياً في الخلفية. وتظهر حالته بوضوح: **خامل (Idle)**، أو **جارٍ الاتصال (Connecting)**، أو **متصل (Connected)**، أو **خطأ في الاتصال (Connection error)**. استخدم زر **إعادة الاتصال (Reconnect)** لإعادة محاولة الاتصال واكتشاف الأدوات.

بعد نجاح الاتصال، يعرض Avro قائمة الأدوات التي يوفرها الخادم. تكون كل أداة مفعلة افتراضياً؛ ويمكنك تعطيل أدوات معينة من محرر الخادم. يؤدي تعطيل الخادم بالكامل إلى استبعاد جميع أدواته من طلبات النموذج القادمة دون حذف تهيئة الخادم.

تنضم أدوات MCP تلقائياً إلى مسار استدعاء الأدوات المدمج في Avro، حيث يرى النموذج اسم الأداة وشرحها ومخطط مدخلاتها البرمجي (Input Schema)، وتُحفظ نتيجة الاستدعاء ضمن سجل المحادثة كالمعتاد.

## تعديل أو إزالة خادم
اضغط على الخادم لتعديل بروتوكول النقل، أو الاسم، أو الرابط، أو الترويسات، وحالة تفعيل الأدوات. يتيح لك زر القائمة إعادة الاتصال أو الحذف النهائي. حذف الخادم يزيل إعداداته ويوقف أدواته مع الاحتفاظ بسجل المحادثات السابقة.

## الأمان والحذر
يمكن لأدوات خوادم MCP أن تحدث تأثيرات خارجية في أنظمتك أو شبكتك. لا تربط إلا الخوادم التي تثق بها، وراجع قائمة أدواتها بدقة، وامنحها أدنى صلاحيات ممكنة، وفضل دائماً استخدام اتصالات HTTPS المشفرة خارج شبكتك المحلية الموثوقة.

## حل المشاكل الشائعة
### خطأ في الاتصال (Connection error)
- تأكد من إمكانية الوصول إلى الرابط من شبكة هاتف الأندرويد.
- تحقق من أن نوع النقل المختار (Streamable HTTP أو SSE) يطابق ما يدعمه الخادم تماماً.
- راجع ترويسات المصادقة وسجلات أخطاء الخادم.
- استخدم خيار "إعادة الاتصال" بعد أي تعديل.

### لا تظهر أي أدوات
- تأكد من تفعيل الخادم وظهور حالة "متصل".
- اضغط إعادة الاتصال لتحديث قائمة الأدوات المكتشفة.
- افتح محرر الخادم وتأكد من تفعيل الأدوات الفردية.

### الأداة لا تُعرض على النموذج
- يجب أن يدعم المزود والنموذج المختار استدعاء الأدوات (Tool Calling). تأكد أيضاً من تفعيل الخادم والأداة المحددة معاً.
