# بروتوكول سياق النماذج (MCP)

يدعم Avro بروتوكول Model Context Protocol لربط النماذج بأدوات خارجية.

## أنواع النقل المدعومة

- **Streamable HTTP**: اتصال سريع بخوادم الـ MCP عن بُعد.
- **Server-Sent Events (SSE)**: تدفق فوري للأحداث والردود من خوادم MCP.
- التحكم الكامل في تفعيل وتعطيل الأدوات المعروضة للنموذج لكل جلسة.
