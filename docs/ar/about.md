# حول تطبيق Avro

Avro هو تطبيق محلي مفتوح المصدر لنظام أندرويد، مصمم كعميل ذكاء اصطناعي وبيئة تشغيل للوكلاء المستقلين مع السيادة الكاملة على البيانات (BYOK).

## المبادئ الأساسية

- **غياب الخوادم الوسيطة**: يتصل التطبيق مباشرة بموفري الذكاء الاصطناعي دون أي خوادم بروكسي أو تجميع بيانات خارجية.
- **التشغيل المحلي**: محادثاتك، أدواتك، وذاكرتك مخزنة محلياً ومشفرة على جهازك.
- **بيئة لينكس مدمجة**: نظام Alpine Linux حقيقي يعمل دون صلاحيات روت عبر PRoot.
- **بروتوكول MCP**: تكامل مباشر مع خوادم Model Context Protocol لتوسيع قدرات النموذج.
