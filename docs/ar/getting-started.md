# دليل البدء السريع (Getting Started)

تطبيق Avro هو عميل أندرويد بنظام BYOK (أحضر مفتاحك الخاص): ما عليك سوى تزويده بمزود الخدمة ومفتاح الـ API واختيار النموذج لبدء الدردشة.

## التثبيت
يمكنك تثبيت Avro من خلال متجر F-Droid، أو Google Play، أو تنزيل ملفات الـ APK مباشرة من قسم الإصدارات (Releases) في مستودع GitHub. تختلف بعض الميزات حسب طريقة التثبيت، وأهمها بيئة Alpine Linux المدمجة المتاحة في حزم F-Droid و GitHub.

## الإعداد لأول مرة
1. افتح القائمة الجانبية للمحادثات واختر **الإعدادات (Settings)**.
2. ادخل إلى **مزودو الخدمة (Providers)**، واختر المزود الذي تريده (مثل OpenAI، Anthropic، Google Gemini، Groq، أو مزود مخصص)، وأدخل مفتاح الـ API ورابط الـ Base URL إن لزم.
3. ادخل إلى **النماذج (Models)**، واضغط على مزامنة نماذج المزود، وقم بتفعيل النماذج التي تريد استخدامها.
4. ارجع إلى شاشة المحادثة واختر النموذج من الشريط السفلي.
5. اكتب رسالتك واضغط إرسال!

تنتقل جميع الطلبات مباشرة من هاتفك إلى نقطة النهاية المحددة للمزود. راجع [مزودو الخدمة](provider.md)، و [إدارة النماذج](models.md)، و [الخصوصية وأمان البيانات](privacy.md).

## البناء من المصدر (Build from Source)
يستهدف المشروع أحدث حزم Android SDK (SDK 36) ويعتمد على بيئة JDK 21 و Gradle الحديثة. يلزم تثبيت Android Studio ومكونات الـ SDK والـ NDK المحدثة لبناء التطبيق بسلاسة باتباع إرشادات المستودع وملفات البناء الجذرية.
