# دليل البداية السريعة مع Avro

## 1. الإعداد الأولي
1. افتح تطبيق **Avro**.
2. من القائمة الجانبية أو شريط الأدوات العلوي، ادخل إلى **الإعدادات (Settings)**.
3. اختر موفر الذكاء الاصطناعي الخاص بك (مثل: Google Gemini أو OpenAI أو Groq أو DeepSeek).
4. أدخل مفتاح الـ API الخاص بك واحفظ التغييرات.

## 2. بدء محادثة جديدة
- اضغط على زر **`+`** لفتح جلسة محادثة جديدة.
- يمكنك كتابة الأوامر النصية، أو إرفاق صور، أو طلب البحث في الإنترنت، أو تشغيل أوامر برمجية عبر الساندبوكس.

## 3. استخدام بيئة ساندبوكس لينكس
- من إعدادات التطبيق، انتقل إلى قسم **Sandbox**.
- قم بتفعيل بيئة Alpine Linux المصغرة.
- يمكنك الآن كتابة نصوص بايثون، تشغيل أدوات CLI، وتنفيذ مهام معقدة بمساعدة النموذج.
